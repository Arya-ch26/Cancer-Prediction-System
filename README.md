# 🩺 Cancer Prediction System

A Machine Learning-based web application that predicts the likelihood of cancer using patient health information. The application is developed using **Python, Flask, and Scikit-learn**, providing a clean and user-friendly interface for real-time cancer risk prediction.

> ⚠️ **Disclaimer:** This project is developed for educational and learning purposes only. The prediction generated by the model should not be considered a medical diagnosis or professional medical advice.

---

# 📖 Overview

The objective of this project is to demonstrate the complete Machine Learning workflow—from data preprocessing and model training to deploying the trained model as an interactive web application.

Users can enter patient information through the web interface, and the application predicts whether cancer is likely to be detected using a trained **Random Forest Classifier**.

---

# ✨ Features

- User-friendly and responsive web interface
- Real-time cancer prediction
- Machine Learning model trained using Scikit-learn
- Prediction confidence display

# 📂 Dataset

This project uses a publicly available **Cancer Prediction Dataset** from **Kaggle**.

The dataset contains patient health information including:

- Age
- Gender
- BMI
- Smoking
- Genetic Risk
- Physical Activity
- Alcohol Intake
- Family Cancer History
- Diagnosis (Target Variable)

The dataset was preprocessed and used to train multiple Machine Learning classification models before selecting the best-performing model.

> **Dataset Source:** Kaggle (Public Dataset)

---

# ⚙️ Project Workflow

1. Collected the dataset from Kaggle.
2. Performed data preprocessing and feature preparation.
3. Split the dataset into training and testing sets.
4. Trained multiple Machine Learning classification models.
5. Compared model performance.
6. Selected the Random Forest Classifier.
7. Saved the trained model and preprocessing pipeline using Joblib.
8. Developed a Flask web application.
9. Created a responsive user interface using HTML, CSS, and JavaScript.

---

# 🤖 Machine Learning Models Evaluated

The following classification algorithms were tested during model development:

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Decision Tree Classifier
- Random Forest Classifier ✅ (Selected)

The **Random Forest Classifier** was selected because it provided the best performance on the dataset.

---

# 📝 Input Features

The prediction is based on the following patient details:

| Feature | Description |
|----------|-------------|
| Age | Age of the patient |
| Gender | Male / Female |
| BMI | Body Mass Index |
| Smoking | Smoking status |
| Genetic Risk | Low / Medium / High |
| Physical Activity | Average hours of exercise per week |
| Alcohol Intake | Average alcoholic drinks consumed per week |
| Family Cancer History | Whether there is a family history of cancer |

# 🚀 Installation

## Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/Cancer-Prediction-System.git
```

## Navigate to the Project Folder

```bash
cd Cancer-Prediction-System
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

## Run the Flask Application

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000/
```
